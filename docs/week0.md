## 🚀 1주차 필수 과제 상세 정리
요청하신 첫 주 차 과제 3가지의 세부 내용입니다.

### 📝 과제 1: 환경 설정 (난이도: 하)
개발 환경 구축을 위해 다음 6가지 체크리스트를 완료해야 합니다.
* **수행 항목:**
    1. Git 설치 후 `git config`로 사용자 이름/이메일 설정
    2. GitHub 계정 생성 및 프로필 설정
    3. 로컬 터미널과 GitHub 간 안전한 통신을 위한 SSH 키 생성 및 등록
    4. Public 설정으로 테스트 레포지토리(`practice-repo`) 생성
    5. Markdown 문법을 사용해 간단한 자기소개 또는 프로젝트 설명을 담은 README.md 작성
    6. 로컬 변경사항을 원격 저장소에 첫 커밋 및 푸시(`git push`)
* **제출 기한:** 1주차 일요일 23:59
* **제출 방법:** GitHub Issue 댓글로 레포지토리 링크 공유

### 📝 과제 2: 프로젝트 주제 제안서 (난이도: 중 / 필수)
한 학기 동안 진행할 개인 프로젝트의 방향성을 구체적으로 작성합니다.
* **포함 내용:**
    * **기본 정보:** 프로젝트명, 개요(한 문장 설명), 동기(Why), 예상 결과물
    * **주요 기능:** 3가지 핵심 기능 (Core Features)
    * **기술 스택:** Frontend, Backend, Database, Deployment 기술 명시
    * **마일스톤:** 4주 단위의 일정 계획 (W1-4 기획/설계, W5-8 MVP 구현, W9-12 고도화, W13-16 최종 발표 등)
* **제출 기한:** 1주차 일요일 23:59
* **제출 방법:** GitHub Issue 작성 (Label: `project-proposal`)

### 📝 과제 3: 자기소개 (GitHub Profile README)
자신을 표현하는 매력적인 GitHub 프로필 페이지를 생성합니다.
* **포함 내용:** 본인 소개, 관심 분야, 기술 스택, 학습 목표, 연락처
* **제출 기한:** 자율 제출 (학기 중 언제든 가능)
* **제출 방법:** 본인 GitHub 계정명과 동일한 이름의 Public Repository를 생성하여 README 작성 (네트워킹용으로 보너스 점수는 없음)
