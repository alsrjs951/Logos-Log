## 🛠️ Feature Flags 주요 개념 및 유형

**Feature Flags**란 코드 배포 없이 런타임에 기능을 켜고 끌 수 있는 메커니즘을 말합니다. 배포와 비즈니스 출시 시점을 분리하고, 문제 발생 시 즉각적인 롤백을 가능하게 합니다.

### 주요 플래그 유형
* **Release Flags (릴리스 플래그):** 완성되지 않은 기능을 숨기고 안전하게 배포하기 위해 사용하며, 수명이 짧습니다.
* **Experiment Flags (실험 플래그):** A/B 테스팅 등을 위해 사용자 경험을 분기하고 데이터를 수집하는 데 사용합니다.
* **Ops Flags (운영 플래그):** 시스템 성능 최적화, 킬 스위치(Kill Switch) 등 런타임 운영 제어를 위해 장기적으로 유지됩니다.
* **Permission Flags (권한 플래그):** 관리자나 프리미엄 유저 등 특정 사용자 그룹에게만 기능을 노출합니다.

## ⚙️ 구현 및 점진적 배포 (Progressive Delivery)

* **구현 방식:** 
  * **환경 변수:** `config.js` 등을 활용하여 제어하지만 동적 제어는 어렵습니다.
  * **코드 기반 관리:** 사용자 ID 해싱을 통해 일관된 롤아웃 비율을 제어합니다.
  * **React/Vue 연동:** Custom Hook(`useFeatureFlag`)이나 Context API를 활용하여 전역 상태로 플래그를 제공합니다.
* **점진적 배포 전략:**
  * **Canary Release:** 1% → 5% → 25% → 100% 등 트래픽을 단계적으로 늘려 위험을 분산시킵니다.
  * **Ring Deployment:** 내부 팀(Canary) → 베타 사용자 → 일반 사용자 순으로 계층을 나누어 순차적으로 배포합니다.

## ✅ Best Practices (모범 사례)
* **명명 규칙:** 의미를 쉽게 파악할 수 있는 `kebab-case`를 사용합니다 (예: `enable-dark-mode`).
* **생명주기 관리:** 플래그의 목적에 따라 수명을 명확히 하고, 사용이 끝난 오래된 플래그는 즉시 코드를 삭제하여 기술 부채를 방지합니다.
* **모니터링:** 플래그 사용 현황과 변경 사항을 추적하여 운영 가시성을 확보합니다.

## 🚀 실습 과제 상세 정리

### 과제 1: Feature Flags 구현
* React/Vue 프로젝트에 Feature Flags 시스템을 구축합니다.
* 최소 3개 이상의 플래그를 구현해야 합니다.
* 환경 변수를 통해 플래그를 제어하도록 설정합니다.
* 설정한 플래그를 실제 컴포넌트에서 사용합니다.

### 과제 2: A/B 테스팅 구현
* 대조군(Control)과 실험군(Treatment)의 2개 Variant를 나누어 다른 UI/UX를 제공하는 로직을 작성합니다.
* User ID 해싱을 통해 동일한 사용자는 항상 같은 그룹에 할당되도록 보장합니다.
* 실험 노출 및 전환(Conversion) 관련 분석 이벤트를 기록합니다.
* 수집된 데이터를 비교하여 승자를 판정하는 결과 분석 스크립트를 작성합니다.

### 과제 3: Progressive Rollout Implementation (Canary 배포)
* 사용자 해싱 또는 그룹을 기반으로 기능 노출을 결정하는 `CanaryRelease` 클래스를 작성합니다.
* 시간 경과에 따라 노출 비율을 1% → 10% → 50% → 100%로 자동 증가시키는 로직을 구현합니다.
* 에러율이 임계값을 초과하면 즉시 롤아웃을 중단하고 0%로 롤백하는 헬스 체크 안전 장치를 추가합니다.
* 배포 단계와 활성 사용자 비율을 보여주는 실시간 모니터링 상태 패널을 구성합니다.

### 과제 4: Feature Flags 플랫폼 통합
* 오픈소스 플랫폼인 Unleash 또는 GrowthBook을 로컬/서버 환경에 설치하고 대시보드를 구성합니다.
* 대시보드에서 기능 플래그를 직접 생성하고 활성화 전략을 설정합니다.
* 제공되는 SDK를 이용해 기존 React/Vue 프로젝트와 관리 플랫폼을 연동합니다.
* 대시보드에서 플래그 변경 시 애플리케이션에 실시간으로 즉시 반영되는지 테스트합니다.
