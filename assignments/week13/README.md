## 3. A/B 테스트 2주 운영 지표 결과

14일간 총 1,000명의 모의 사용자를 대상으로 `new-chat-ui` 실험을 무중단 구동한 일자별 누적 결과 데이터입니다.

- **실험 기간**: 2026-05-15 ~ 2026-05-29 (14일간)
- **대상자 할당 방식**: MD5 해싱 모듈을 활용한 유저 ID 기반 결정론적 배정
- **일자별 상세 지표 로우 데이터**: [daily_metrics.json](file:///Users/lmg/Projects/Logos-Log/assignments/week13/data/daily_metrics.json)

### 누적 성능 비교표

## 4. Pivot 또는 Persevere 의사결정서

### 통계적 검정 결과 (Z-Test)
- **Z-Score**: `10.8752` (임계값 1.96 초과)
- **P-Value**: `1.4725e-27` (유의 수준 $\alpha = 0.05$ 미만)
- **통계적 유의성**: **유의미함 (Significant - 귀무가설 H0 기각)**

### 💡 의사결정: Persevere (수성 및 100% 전면 도입)

Z-검정 결과 P-Value가 유의 수준인 0.05보다 압도적으로 낮게 계산되었으며, Z-Score 역시 임계 기준인 1.96을 한참 초과하여 실험 결과의 우연성(Random Chance) 배제가 입증되었습니다.

- **결정 사유**:
  - Variant B(신규 인터페이스 UI)는 기존 UI 대비 클릭 전환율이 약 **+72.7%** 상대 개선되는 엄청난 비즈니스 성과를 보였습니다.
  - 가상 페르소나 피드백(임소윤, 송준서, 이다혜 등)에서도 넓어진 다단 입력란과 업무 Context 검색 필터가 실무 및 장문 작성 환경에 쾌적하다는 긍정적 사용자 가치 증명이 일어났습니다.
- **향후 로드맵**:
  - Feature Flag 배포 설정을 변경하여 `new-chat-ui` 플래그의 기본 할당 비율을 **100%**로 고정하고, 기존 A안 코드를 점진적으로 리팩토링 및 제거합니다.
  - 해당 주간 실험 결과 리포트는 GitHub Actions를 통해 저장소의 Issue 게시판으로 자동 이첩되어 전체 개발 스쿼드에 리포팅 완료되었습니다.
